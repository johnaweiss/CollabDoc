# CollabDoc

CollabDoc lets you edit a local HTML file in your browser and save it back to your computer. Install it as an app from https://johnaweiss.github.io/CollabDoc/, open a file, edit the text on the page, and save.

## CollabDoc CLI

The CollabDoc CLI lets AI agents edit the rendered content of a web page without opening the page in a browser. The agent loads an HTML file, changes its text, then either saves the change (commit) or throws it away (cancel). Changes stay in memory until they are committed.

Download it from the app with the **Download CollabDoc CLI** link. Windows only for now.
